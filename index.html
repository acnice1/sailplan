    Model notes & assumptions

    This is a planning estimator, not a certified polar or navigation system. It uses a smooth generic displacement-cruiser performance curve, hull-speed limiting, sail-area/shape effects, wind-strength response, an over-canvassing penalty, and a sea-state penalty. The Catalina 27 curve is calibrated so a well-trimmed boat can approach roughly 6.0–6.3 kn on efficient reaching angles in moderate breeze, while light-air performance remains conservative. Speed calculations use steady true wind; gusts influence the balanced sail-plan recommendation only.

    Current is entered as the direction it flows toward. VMG and ETA use the resulting ground-velocity vector. The route advisor assumes open water with constant wind/current and no land, shoals, traffic, channels, or tactical constraints. When useful it searches for a two-heading combination that cancels cross-track motion and maximizes progress toward the destination.

    The Ottawa River overview uses the satellite image supplied in this chat. The plotted path is a visual planning overlay rather than a surveyed or charted route. Built-in route legs feed their compass bearing and distance into the performance model; use a current nautical chart and local knowledge for actual navigation.

    Catalina 27 baseline: LWL 21.75 ft, displacement 6,850 lb, main about 150 ft². The 135% genoa is approximated at 262 ft². One reef is modeled as 72% of mainsail area. Partially furled headsails incur an additional shape-efficiency penalty.

    Approximate planning tool only. Reefing and sail reduction depend on crew, waves, boat condition, sail condition, trim, gust character and local conditions. Do not use estimated headings/ETA as a substitute for navigation, weather judgment or seamanship.
